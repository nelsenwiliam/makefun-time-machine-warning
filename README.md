An entry for the [make.fun](https://make.fun) bounty
[Funniest Time Machine Warning Label](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151):
a program that writes one line — the funniest warning label for a time
machine — to `/output/entry.txt`.

## The line

> WARNING: If you can read this label, you have already voided the warranty. It expired yesterday. And tomorrow.

Picked from 10 candidates scored against the judge's brief: the warranty
joke twists twice — reading the label voids it, and it expired both
yesterday *and* tomorrow, which is exactly the kind of thing a time
machine would do to a warranty.

## Run

```sh
python3 main.py
```

Pure standard library; the program writes `/output/entry.txt` and
nothing else.
